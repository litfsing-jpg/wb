# 10 СЛАЙДОВ ДЛЯ АВИТО

**Стиль:** Минималистичный, профессиональный
**Цвета:** Тёмный фон + яркие акценты (или светлый + контрастный текст)

## ИНСТРУКЦИЯ ПО СОЗДАНИЮ:

### Инструменты:
1. **Canva** (бесплатно) — есть готовые шаблоны
2. **Figma** (бесплатно) — для кастомного дизайна
3. **Tilda** — можно экспортировать как картинки

### Параметры:
- Размер: 1080×1080 px
- Формат: JPG или PNG
- Качество: Максимальное

### Стиль рекомендации:
- **Вариант 1:** Тёмный фон (чёрный/тёмно-синий) + белый текст + яркие акценты (жёлтый/оранжевый)
- **Вариант 2:** Светлый фон + тёмный текст + цветные иконки
- **Вариант 3:** Градиент + белый текст

### Шрифты:
- Заголовки: Жирный, без засечек (Montserrat Bold, Inter Bold)
- Текст: Средний, без засечек (Open Sans, Roboto)
